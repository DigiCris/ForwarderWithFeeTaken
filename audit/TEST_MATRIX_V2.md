# Test matrix — Forwarder V2 (vault change lifecycle)

Requirement → evidence across tools. Section numbers refer to the V2 request. The V1 matrix (fees, forward, treasury,
rescue, routing) is [TEST_MATRIX_V1.md](TEST_MATRIX_V1.md); that code is unchanged and its suites run as regression
(report section E).

Legend — **U** unit (`test/ForwarderVaultChange.t.sol`, `test/ForwarderVaultAndRescue.t.sol`, `test/Forwarder.t.sol`),
**F** fuzz (`test/ForwarderVaultChangeFuzz.t.sol`), **I** Foundry invariant (`test/ForwarderVaultChangeInvariant.t.sol`),
**E** Echidna property (`echidna/ForwarderVaultChangeEchidna.sol`), **C** Certora rule/invariant
(`certora/specs/ForwarderV2.spec`), **K** Base fork (`test/fork/ForkTestBase.sol`), **M** mutant killed
(`audit/raw/v2/mutation/`).
